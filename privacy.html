개인정보처리방침

시행일: 2026년 10월 24일

1. 처리하는 정보

사용자가 로그인을 허락하면, 사용자 본인 구글 드라이브의 지정 폴더에 있는 노트 파일을 읽고 씁니다. 그 밖의 개인정보는 수집하지 않습니다.

2. 이용 목적

휴대폰과 PC 사이의 노트 동기화에만 씁니다.

3. 저장과 제공

노트와 로그인 정보는 사용자 기기와 사용자 본인의 구글 드라이브에만 저장됩니다. 별도 서버에 저장하거나 제3자에게 제공·판매하지 않습니다.

4. 구글 사용자 데이터

구글 API로 받은 정보는 Google API Services User Data Policy(제한적 사용 요건 포함)를 따라 동기화 기능에만 사용합니다.

5. 철회

구글 계정 설정의 서드 파티 액세스에서 언제든 접근 권한을 해제할 수 있습니다.
